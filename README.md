# Web Metronome

インストール不要・スマホ対応のシンプルなWebメトロノーム。ビルド不要（素のHTML/CSS/JS）。

## 機能
- BPM指定（30〜300、±ボタン/スライダー/直接入力）
- タップテンポ
- プリセット（BPM・拍子・音色を名前付き保存、ワンタップ切替）
- 拍子・アクセント設定（2/4, 3/4, 4/4, 5/4, 6/8, 7/8 + 1拍目強調）
- 拍子音の複数音色（Click / Wood / Beep / Cowbell）
- ハプティクス（対応端末のみ）
- 画面スリープ防止（Wake Lock API）
- 視覚メトロノーム（画面フラッシュ + 拍数表示、サイレントモード対応）
- スピードトレーナー（自動テンポアップ）
- カウントイン（1〜2小節の予備拍）
- シャッフル（スウィング）モード
- ダークモード
- PWA対応（オフライン起動、ホーム画面追加）

## ローカル確認
```
python -m http.server 8000
```
`http://localhost:8000` にアクセス。

## 公開（GitHub Pages）
リポジトリの Settings > Pages で、ソースを `main` ブランチ / ルートディレクトリに設定する。
